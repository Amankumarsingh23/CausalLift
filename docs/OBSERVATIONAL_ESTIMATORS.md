# Observational estimators

The benchmark estimates effects on the fixed synthetic validation populations. Training OOF is a separate population. A uses known randomized assignment. C assumes observed backdoor sufficiency, with engagement and loyalty confounding assignment and baseline risk. The nuisance models use the full pre-treatment allowlist. Consistency, exchangeability and positivity are required. F has an open hidden backdoor path. Improvements in measured balance cannot repair that failure.

Standardization fits one outcome model per arm on training. Logistic and LightGBM predict binary outcome probabilities. ATE averages the prediction difference over all eligible rows. ATT uses treated rows. Matching uses nearest logit propensity with replacement and a caliper of 0.2 sample SD of pooled logits. Distance ties favor lower logits and then earlier control rows. This deterministic convention can reuse a single control for constant scores. Caliper-excluded treated rows change the target to matched ATT. Control multiplicities enter the balance calculation. Formal matching inference is unsupported.

Horvitz–Thompson divides the signed inverse-weighted outcome sum by the population size. Hájek normalizes each inverse-weighted arm mean. ATT weights are one for treatment and e/(1−e) for control. Diagnostic stabilized ATE weights multiply the treatment and control inverse weights by their respective empirical assignment shares. ESS is squared total weight divided by sum of squared weights. Flags use maximum weight above 20 or ESS below half the rows. Balance units are the unadjusted pooled arm SD from Session 03 for every weighting or matching method.

AIPW averages mu1−mu0 plus treated residual/e minus control residual/(1−e). The external ATT analogue averages treated residuals relative to the control prediction and subtracts odds-weighted control residuals, then divides by the treated share. SE is the sample SD of the estimated influence score divided by square root n. Wald intervals are approximate, conditional on independent rows and adequate nuisance quality and overlap. Cross-fitted training estimates use the same three folds for propensity and both outcome models. Saved C and F predictions are reused only after checking ordered partition fingerprints, unit IDs, labels, feature configuration and fold assignments.

Clipping to [0.05, 0.95] modifies weights while retaining the rows and may introduce bias. Restricting to that range changes the evaluation population and its truth is recomputed. No safeguards silently modify the primary estimate. The four oracle robustness cases use X equally likely to be −1 or +1, e=0.5+0.25X, mu0=0.35+0.15X and mu1=mu0+0.10. Wrong score models drop X. Results illustrate conditional double robustness and do not guarantee finite-sample intervals.

## External benchmark and reproduction

The Dehejia–Wahba RE74 variant uses 185 NSW experimental treated, 260 experimental controls, and 15,992 CPS nonexperimental controls. Columns are assignment, age, education, Black, Hispanic, married, no degree, 1974 earnings, 1975 earnings and 1978 earnings. Only the eight baseline covariates enter models. We found no explicit redistribution grant on the publisher page, so raw data remain local. The run verifies publisher file hashes and counts. [Publisher data and cohort definitions](https://users.nber.org/~rdehejia/nswdata.html)

The observational holdout is a seeded 40% stratified split. Arm-specific standardization uses Ridge on raw continuous earnings, and propensity uses logistic regression. All 260 randomized controls supply a reference for the same 74 held-out NSW treated individuals. The reference is a sample estimate. CPS comparability, eligibility differences and weak overlap constrain interpretation.

Run `python -m causallift.session09 --download` to fetch the publisher files if needed, then `python -m causallift.session09`. The benchmark uses local Session 01 and 08 artifacts. Default mode records unavailable external files while still building synthetic outputs. `--fixture` requires no prior artifacts or network. [Completion report](session-09-completion.md)
