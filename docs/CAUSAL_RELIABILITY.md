# Causal reliability diagnostics

Session 10 preserves the published Session 09 artifact tables and reproduces the original matching rule alongside the corrected results. The default nearest-logit matcher rotates through controls with identical scores. For equally distant score groups it takes the next control with the smaller reuse count, breaking a remaining tie by lower logit. It uses position and previous reuse only, stays inside the unchanged pooled-logit SD caliper, and retains replacement and matched ATT. Formal inference remains unsupported.

The randomized A placebo independently shuffles assignment in training and validation, preserving counts in each, and refits arm outcome models. Its known randomized propensity remains fixed. Nominal interval rejection is a pipeline diagnostic for these permutations. C's random-feature refutation generates independent Gaussian noise in each partition and refits both propensity and outcome models. Subsets use 80% of each arm in each partition without replacement, with seeds and ordered unit hashes to reconstruct subsets. Their quantiles describe variation rather than confidence limits. Subset truth averages true effects on the realized evaluation subset.

The continuous simulation draws independent standard normal X, U and errors. Assignment follows sigmoid(0.7X + sU), the main outcome is T + 0.9X + sU + error, and the negative control is 0.9X + sU + independent error with no T term. The five strengths are 0, 0.4, 0.8, 1.2 and 1.6. The main effect is 1 throughout. Observed estimators use X only. The full-information diagnostic uses X and U with fitted nuisances. Split-half fitting keeps evaluation observations independent of nuisance fitting. Paired simulation seeds hold the random streams fixed across strengths. True and fitted propensity tail shares help separate omitted confounding from changing support. This simulation is not a bound on real-world bias. Negative-control validity requires a credible exclusion from treatment and relevance to the bias mechanism. [Negative control reference](https://pubmed.ncbi.nlm.nih.gov/20335814/)

Overlap diagnostics compare verified Sessions 08 logistic and LightGBM scores and known design A. Clipping changes scores at fixed population size. Restriction changes the target and therefore recomputes truth. Diagnostic flags use maximum weight above 20 or arm ESS below half the unweighted count. These are transparent heuristics. The structured report gives identification precedence over otherwise reassuring diagnostics and retains the previous 0/30 DML coverage finding.
